## Как дополнить библиографию

Если вы нашли **новый источник**:

1. **Определите** его тип (архивный, нарративный, картографический, научный).
2. **Добавьте** в соответствующую секцию.
3. **Укажите** фонд, опись, дело, лист (для архивных).
4. **Укажите** автора, название, издание, год, страницы (для публикаций).
5. **Отметьте** статус (подтверждено / требует проверки / гипотеза).
