# Архивные источники

> **Назначение:** сводный перечень архивных фондов, в которых содержатся документы, связанные с родом Танашевых.
> **Принцип:** указание фонда, описи, дела и краткого содержания.
> **Статус:** перечень **пополняется** по мере обнаружения новых документов.

## VII. Как дополнить перечень

Если вы нашли **новый архивный документ**:

1. **Определите** архив, фонд, опись, дело, лист.
2. **Кратко опишите** содержание (кто, что, когда).
3. **Добавьте** в соответствующую секцию (по архиву).
4. **Укажите** статус (подтверждено / требует проверки / гипотеза).
